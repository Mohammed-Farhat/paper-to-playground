1. The idea

Attention answers a simple question: for each query, which of the stored keys look most similar, and how should I mix their values? We measure similarity with a dot product. If query q and key k point the same way, q⋅k is large; if they are unrelated, it is near zero.

Raw dot products are not yet weights. We pass each row of scores through a softmax, which exponentiates and renormalizes so the row becomes a probability distribution: all entries non-negative and summing to 1. A large score grabs most of the weight, so the output for that query is mostly the value attached to the best-matching key.

The scaling factor 1/dk is the 'scaled' in the name. With dk components, a dot product of independent mean-0 variance-1 vectors has variance dk, so scores grow like dk in magnitude. Large scores push softmax into saturation, where its gradients are tiny. Dividing by dk keeps scores in a well-behaved range.

The output is then just a weighted average of the value rows: O=AV. Row i of O is a convex combination of the rows of V, with the attention weights as the mixing coefficients.

Why it matters

This one equation is the core of the Transformer: every attention head, and every layer of the encoder and decoder, is this computation. Understanding the score-to-softmax-to-weighted-sum pipeline makes multi-head attention, masking and cross-attention readable rather than mysterious.

    4. Guided explorations

    Exploration 1: Equal scores give uniform weights

    Change
    Leave Q at all zeros, then drag one entry of Q away from zero.
    Observe
    With Q all zeros every score in the left heatmap is 0, so every weight in the right heatmap is 1/m and each row-sum readout shows 1.000. The output bars sit at the plain average of the value rows. Moving one Q entry breaks the tie and shifts weight toward the best-matching key.
    Why
    Softmax of a constant vector is uniform: exp(c)/∑jexp(c)=1/m. Equal similarity means equal attention, and the output is the unweighted mean of V.

    Exploration 2: A dominant score concentrates attention

    Change
    Turn the scaling toggle off, then back on, and compare the weight heatmap.
    Observe
    With scaling on, query q1=(3,0) scores 3 against k1 and 0 against k2, so after dividing by 2 the weights are roughly 0.88 / 0.06 / 0.06 and the output row is close to v1. With scaling off the same scores are 3 and 0, giving weights near 0.95 / 0.02 / 0.02: the row is more peaked and the output is even closer to v1.
    Why
    Dividing by dk shrinks the score spread before the exponential, so the softmax is less saturated. That is exactly the effect the paper cites for large dk, where unscaled dot products grow in magnitude and softmax gradients become extremely small.

    5. Misconception: The weights are not the output

    The attention weight matrix A is only an intermediate. The output is O=AV, a weighted average of the value rows, so it lives in ℝdv and has nothing to do with the size of the scores. Changing V leaves A untouched but changes O completely; changing K changes A and therefore O.

    6. Source grounding

    Paper: Attention Is All You Need (Vaswani et al., 2017) — https://arxiv.org/html/1706.03762v7

    Relevant part: Section 3.2.1, Equation 1 (with Footnote 4)

    Supported by the source excerpt

    • The input consists of queries and keys of dimension dk, and values of dimension dv.
    • The dot products of the query with all keys are computed, each is divided by dk, and a softmax function is applied to obtain the weights on the values.
    • The attention function is computed on a set of queries simultaneously, packed into a matrix Q; keys and values are packed into K and V.
    • The output is Attention(Q,K,V)=softmax(QK⊤/dk)V (Equation 1).
    • Dot-product attention is identical to this algorithm except for the scaling factor 1/dk.
    • For large dk the dot products grow large in magnitude, pushing the softmax into regions with extremely small gradients; the dot products are scaled by 1/dk to counteract this.
    • Footnote 4: if the components of q and k are independent random variables with mean 0 and variance 1, then q⋅k=∑i=1dkqiki has mean 0 and variance dk.

    3.2.1 Scaled Dot-Product Attention. The attention used is called "Scaled Dot-Product Attention". The input consists of queries and keys of dimension d_k, and values of dimension d_v. The dot products of the query with all keys are computed, each is divided by sqrt(d_k), and a softmax function is applied to obtain the weights on the values. In practice the attention function is computed on a set of queries simultaneously, packed together into a matrix Q; the keys and values are packed into matrices K and V. The matrix of outputs is computed as: Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V (Equation 1). The two most commonly used attention functions are additive attention and dot-product (multiplicative) attention. Dot-product attention is identical to this algorithm except for the scaling factor 1/sqrt(d_k). Additive attention computes the compatibility function using a feed-forward network with a single hidden layer. The two are similar in theoretical complexity, but dot-product attention is faster and more space-efficient in practice because it can use optimized matrix multiplication. For small d_k the two mechanisms perform similarly, but additive attention outperforms dot-product attention without scaling for larger d_k. The authors suspect that for large d_k the dot products grow large in magnitude, pushing the softmax into regions where it has extremely small gradients; to counteract this, the dot products are scaled by 1/sqrt(d_k). Footnote 4: to illustrate why the dot products get large, assume the components of q and k are independent random variables with mean 0 and variance 1; then their dot product q . k = sum_{i=1}^{d_k} q_i k_i has mean 0 and variance d_k.
